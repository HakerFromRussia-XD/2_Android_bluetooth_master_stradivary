# Аудит оставшихся пакетов shared для V3

Дата: 2026-10-05. Ветка: `kmm_ubi4_with_clean_arch`.
Область: снимок 203 Kotlin-файлов commonMain вне `ubi4/versions/v3` до K7.2.1.
Связанные потребители проверены в Android, shared и Swift; Native-экспорт не проверялся.

## Результат и смысл решений

| Решение | Файлов | Что это означает |
|---|---:|---|
| Оставить | 109 | Общие источники, модели, кодеки, правила, UI или платформенные контракты уже имеют допустимую ответственность. Их расположение вне v3 не требует переноса. |
| Отложить выделение/API | 76 | Есть смешанные обязанности, общие состояния или экспортируемый API. Дальнейшее изменение требует проверки iOS/потребителей либо выходит за текущий шаг. Это не 76 обязательных переносов. |
| Исключён из изменений | 16 | Парсеры, сохранённый DataFactory, UBI4/training/legacy обязанности вне разрешённой V3-работы. |
| Предметный кандидат | 2 | Найдены две конкретные V3-обязанности. Один кандидат допускает небольшой ближайший перенос, второй относится к ранее незавершённой служебной прошивке. |

Подтверждённых заменённых дублей для удаления в этой инвентаризации не найдено.
Отсутствие текстовых ссылок само по себе не доказывает, что модель можно удалить:
есть сериализация, expect/actual, экспорт и незаменённые wire-варианты.
Количество файлов не используется как процент готовности архитектуры.

## Кандидаты и выполнение

1. **K7.2.1 — отправитель телеметрии V3, файл перенесён 2026-10-05.** Существующий `Ubi4TelemetrySender`
   используется только `V3TelemetryRepositoryImpl` и Android `BleDependencies`.
   Внутри проверяет V3, запрашивает счётчики, ждёт свежие данные до 5000 мс,
   проверяет присутствие допустимого ID, лениво применяет fallback и отправляет POST.
   Файл размещён в существующем `versions/v3/data/telemetry`, потребители
   переключены, прежняя копия удалена. Тела отправителя и исключений идентичны;
   нового класса, UseCase или интерфейса нет. Общие HTTP API/payload сохранены.
   Порядок событий, `receivedAtMillis >= requestStartedAt`, timeout, условия
   непустых счётчиков, правила ID/fallback, cancellation и mapping ошибок не менять.
   Наличие двух data-классов само по себе не доказывает дублирование алгоритма;
   объединение с репозиторием рассматривать только по реальной ответственности.
2. **C5.3.2 — служебный выбор прошивки V3, перенесены C5.3.2.1–C5.3.2.3.**
   На момент аудита `AccountFragmentMainV3` сам загружал каталог и отбирал архивы.
   Теперь эти обязанности проходят через существующую экранную ViewModel →
   общие UseCase → Repository. Прежние shared-функции сравнения/совместимости
   подключены DI, без копирования и перемещения публичных Firmware* типов.
   Прошли 978 app-тестов и debug/release; UI, метаданные, порядок новых версий
   первыми, BLDC, общий `FirmwareVersionCatalog`, UBI4 и Swift API сохранены.
   C5.3.2.2: скачивание всех кандидатов перенесено через ту же ViewModel →
   общий UseCase → существующий Repository; сетевой цикл/Job из Fragment удалены.
   Порядок, кэш, отмена и прежние сообщения/диалог сохранены. Новых рабочих файлов
   нет; 987 app-тестов и debug/release прошли. C5.3.2.3 перенёс формирование/кэш
   списка плат и оба потока обновлений за существующую ViewModel и общий domain/data.
   Исходные общие хранилища/enum не изменены, UBI4-путь сохранён. Очередь UiState
   сохраняет порядок прямых/отложенных отправок в адаптер. Далее V3-ветка
   DialogManager; прошли 1017 app-тестов и debug/release. Телефон/Native/iOS/
   полный shared-набор не проверялись. Подробности — разделы 52–54 основного shared-плана.


Проверка K7.2.1: 965 app-тестов, включая архитектуру, телеметрию и DI, прошли;
debug/release собраны. Новых классов и дополнительных исходных файлов нет;
рабочего кода на одну строку меньше. Телефон/Native/iOS/полный shared-набор
на этом переносе не проверялись. Подробности — раздел 51 основного shared-плана.

После каждого переноса проверять реальных потребителей, архитектуру и поведение;
старый алгоритм не оставлять вторым экземпляром. Массового переезда 203 файлов нет.

## Переключатель V3 — не следующий шаг

`SwitcherDelegateAdapterV3` зарегистрирован только в общем composite
`BaseWidgetsFragment`. Разрешённые V3-ветки Sensors/SpecialSettings/Service/
SprGesture создают собственные composites без этого адаптера. Действующие
`generatedHardcodeWidgets` для V3/INDY3 не создают switcher; registry сохраняет
тестовый subcommand 0xFF. AdvancedFragment исключён пользователем.

Это прежний остаток раздела 27 основного плана. Сохраняем адаптер, RetryUtils,
кодеки и модели; новый UI/сценарий ради рефакторинга не создаём.

## K6.14 — оставшиеся границы прошивки

- Чистые правила, Coordinator/backend-контракт и состояние находятся в domain;
  архивы/журнал — в существующем V3 data-репозитории. Повторного алгоритма queue/
  completed/retry в UserFirmwarePolicy нет: совместимые методы делегируют policy.
- UserFirmwareUpdates/Host/UiState/Archive — действующий вход Android/iOS;
  UserFirmwareActivity читают защищённый Android BLEController и iosMain BLE manager.
  Их дальнейшее разделение/экспорт отложены, публичные типы сохраняются.
- Низкоуровневые DFU, CRC, descriptor, transport expect/actual и общие UBI4/V3
  updaters относятся к инфраструктуре/data. Копирование их в V3 domain не нужно.
- Статический аудит K6.14 завершён; K6 не объявляется полностью проверенным на iOS.
  Незавершённый C5.3.2 остаётся отдельным служебным сценарием.

## Проверки и ограничения аудита

Списки четырёх областей сверены с фактическими файлами: data 101, models/utility/
achievements/persistence/корневые классы 60, integration/общий UI 28, firmware 14.
Всего 203 уникальных пути, без пропусков и повторов. Проверены 681 строки evidence
на существование файла и соответствие текущему исходнику.

Это статический аудит размещения, обязанностей и потребителей; поведение каждого
метода не перепроверялось на устройстве. При инвентаризации исходники не менялись,
сборки, тесты и аппаратные проверки не запускались. На тот момент проверка кода — K6.13:
965 app-тестов и debug/release; полный shared-набор имеет известный блокер
BindingGroupV3Test, Native/iOS-проверки отложены.

Ограничения сохраняются: UBI4, by_Misha/by_Radeon, BLEController и оба BLEParser
не рефакторить; DataFactory/generatedHardcodeWidgets и существующий UI сохранить.
Платформенные androidMain/iosMain — отдельная ось KMM; они не становятся domain.
