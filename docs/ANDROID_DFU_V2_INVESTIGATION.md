## Правила продолжения работы

- Перед новой гипотезой читать этот файл. Дописывать результаты сюда, не создавать отдельные журналы попыток.
- Не повторять отклонённые изменения под другим названием. Возврат к ним допустим только с новым проверяемым основанием, записанным здесь до изменения кода.
- Различать: полный прогон неуспешен; проверяемый участок не достигнут; гипотеза опровергнута; причина доказана. Это разные результаты.
- Для каждой попытки фиксировать базу/сборку, изменения, ожидаемую проверку, аппаратный результат, факты логов, вывод и статус отката.
- Успешная компиляция и модельные тесты НЕ доказывают прошивку устройства. Успех v2: выбран v2, переданы данные именно v2, принят CRC, подтверждён MAIN. Автоматический успешный повтор v1 не считать успехом v2.
- Пользователь ограничил исправления пайплайном Android v2. Не менять v1, общий вход main→boot, бутлоадеры, дашборды, ID/подпись приложения или рабочую ветку без отдельного указания.
- Не утверждать причину зависания FAM по одному таймауту Android. Запись ATT с status=0 не доказывает выполнение команды или сохранение состояния платой.
- Пользователь подтвердил одинаковую подготовку каждого теста v2 (см. ниже). Не повторять вопрос о подготовке и не объяснять неудачу «остатками предыдущего прогона» без новых прямых доказательств. Фактическое содержимое Flash агент здесь не проверял.
