## MODIFIED Requirements

### Requirement: V3 device-name editing preserves the received prefix mode
Система SHALL на Android и iOS показывать изменяемую часть имени стандартного V3 или INDY3 без распознанного семейного префикса. При записи система SHALL определять режим по текущему полному имени устройства: если оно содержит распознанный префикс, система SHALL сохранить существующее поведение восстановления префикса активного профиля; если текущее имя не содержит распознанного префикса, система SHALL отправить, сохранить и отобразить введённое имя без автоматического добавления префикса. Введённый вручную распознанный префикс SHALL быть удалён перед применением режима текущего имени. Итог BLE-записи и немедленно обновлённое локальное имя SHALL совпадать. Программное заполнение Android-поля SHALL использовать фактическую длину установленного текста и SHALL NOT повторно заменять текст при касании или перемещать курсор в конец.

#### Scenario: User renames an INDY3 device
- **WHEN** устройство передало текущее имя `INDY3-0000000000`, а пользователь сохраняет имя `MY-HAND`
- **THEN** поле отображает `0000000000`, а Android и iOS отправляют и сохраняют `INDY3-MY-HAND`

#### Scenario: User renames a standard V3 device received with prefix
- **WHEN** стандартное V3-устройство передало текущее имя `FTHS3-0000000000`, а пользователь сохраняет имя `MY-HAND`
- **THEN** поле отображает `0000000000`, а Android и iOS сохраняют существующее поведение и отправляют `FTHS3-MY-HAND`

#### Scenario: Device name was received without prefix
- **WHEN** устройство активного профиля V3 или INDY3 передало текущее имя `0000000000`, а пользователь сохраняет имя `1234567890`
- **THEN** Android и iOS отправляют, сохраняют и отображают `1234567890` без добавления `FTHS3-`, `INDY3-` или другого семейного префикса

#### Scenario: Prefix-free name is edited repeatedly
- **WHEN** приложение уже отправило и сохранило имя `1234567890` без префикса, а пользователь в том же соединении сохраняет новое имя `9876543210`
- **THEN** система использует обновлённое текущее имя как источник режима и отправляет `9876543210` без префикса

#### Scenario: User enters a known prefix manually
- **WHEN** пользователь вручную вводит распознанный V3/INDY3-префикс перед изменяемой частью имени
- **THEN** система удаляет введённый префикс и формирует итоговое имя по режиму текущего полного имени устройства без дублирования или самовольной смены режима

#### Scenario: Prefix-only input produces an empty editable name
- **WHEN** после удаления окружающих пробелов и распознанного префикса изменяемая часть имени пуста
- **THEN** система не отправляет BLE-команду записи имени

#### Scenario: Prefilled name exceeds the editable limit
- **WHEN** программно подставляемая изменяемая часть имени длиннее 13 UTF-8 байт и ограничитель обрезает текст
- **THEN** Android устанавливает курсор по фактической длине текста без `IndexOutOfBoundsException`

#### Scenario: User moves the cursor inside the name
- **WHEN** пользователь касается середины заполненного Android-поля имени
- **THEN** поле не заменяет текст повторно и оставляет курсор в выбранной пользователем позиции
