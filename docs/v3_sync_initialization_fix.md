# V3: остановка на синхронизации, 2026-09-09

Пользователь воспроизвёл зависание на обычном V3; старая версия приложения
с тем же устройством работала. Диагностика выполнена через USB/logcat.

В установленной release-сборке 3.3.1827 GATT успешно подключается, MTU
согласован, сервисы найдены. Затем BLEController пишет:

```text
controller normal_init suppressed dfu_active=false firmware_session=false bootloader_v2_transport=true
```

`listWidgets.size=0`: инициализация и генерация виджетов не запущены.
Причина — проверка `supportsWriteWithoutResponse(SERIALPORTCHAR_UUID)` как
признака bootloader. У обычного V3 SerialPort имеет properties=28 и также
поддерживает WRITE_NO_RESPONSE. Это свойство транспорта не определяет режим платы.

Проверка существовала в HEAD до миграции Slider (git blame: 4ce9b6f306,
2026-09-03). На этом запуске до нового ViewModel дело не дошло.

Исправление в Android BLEController: нормальная инициализация больше не
блокируется только из-за WRITE_NO_RESPONSE. Ветки активной firmware-сессии
и DFU-reconnect сохранены. Парсеры, форматы команд, очередь и прошивка устройства
не изменялись. Загрузчик, запущенный вне управляемой firmware-сессии приложения,
этой проверкой не распознаётся; восстановление загрузчика требует отдельного
предусмотренного для него сценария, как описано в FirmwareUpdateBridge.

Debug-сборка и 48 app-тестов успешны. Установка debug поверх имеющейся release
отклонена Android из-за разных подписей; приложение и его данные не удалялись.
Лог сборки: `/tmp/ubi4-sync-fix-20260909.log`.
Исходный лог приложения: `/tmp/ubi4-sync-app-20260909.txt`.

Release-сборка с настроенной подписью успешно собрана и установлена через
`adb install -r` поверх приложения. После запуска подтверждено на физическом V3:
генерация 22 виджетов, входящие ответы начальных запросов (включая GET скорости
`00 0F 3E 64 AA`), отсутствие прежней блокировки normal_init. UI dump показывает
экран «Датчики» с параметрами и нижней навигацией; диалога синхронизации нет.
Данные приложения сохранены, настройки виджетов вручную не менялись.

Логи: `/tmp/ubi4-sync-fix-release-20260909.log`,
`/tmp/ubi4-sync-fixed-app-20260909.txt`;
снимок UI: `/tmp/ubi4-sync-fixed-ui-20260909.xml`.
INDY3, загрузчик и обновление прошивки в этой проверке не запускались.
