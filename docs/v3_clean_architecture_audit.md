# Проверка versions/v3: Clean Architecture, MVVM и MVI

Дата: 2026-09-16. Область: весь пакет `app/.../ubi4/versions/v3`, его
Android-подключения и тесты. Это проверка уже перенесённых сценариев, а не
объявление завершённой миграции всего приложения. Состав Gradle-модулей сохранён.

Уточнение области 2026-09-16 по заданию тимлида, переданному пользователем:
рефакторинг только V3; этап UBI4 исключён. Общие Fragment остаются на текущих
местах. Проверяем границы V3 и сохранность UBI4-потребителей, а не требуем
переноса всей оставшейся логики общего файла. Общая переработка DataFactory,
BaseWidgetsFragment и 3D-рендера не входит в эту задачу. Детали — в основном плане.
Пользователь разрешил правки общих файлов при сохранении логики обеих версий;
такие правки требуют проверки затрагиваемых UBI4-потребителей.

## Обязательный контракт

`UI Action → экранная ViewModel → UseCase → domain Repository → data implementation`.
Чтение и подписки также проходят через UseCase. Результаты ViewModel преобразует
в неизменяемый `UiState`, который Fragment отображает. `render` не отправляет команд.
В presentation UseCase вызывает только ViewModel; фабрики собирают зависимости в `di`.

Это выбранное для проекта строгое правило. Само по себе использование domain-интерфейса
репозитория в presentation не запрещается всеми вариантами Clean Architecture,
но в этом проекте оно больше не допускается.

Обработка кадров графика сохраняет интервал 25 мс. Проверка паузы выполняется
отдельным лёгким UseCase: значения порогов не декодируются на каждом кадре.
При чтении жестов ViewModel получает один согласованный снимок вместо повторного
чтения активного жеста и группы.

## Границы совместимости

`shared` является модулем, а не отдельным слоем. Существующий `DataFactory`
фильтрует и сортирует уже созданные описания, подставляет подписи и создаёт UI Items.
Эта работа относится к presentation, несмотря на историческое имя папки `data`.
Поэтому UI-состав и старые widget-структуры **не перенесены в domain**.

Три `DataFactoryV3*WidgetsSource` и три `V3*WidgetMapper` сохраняют связь с этим
общим UI-кодом и прежними Android-адаптерами. Они могут использовать `DataFactory`,
структуры UI и registry метаданных. Они больше не читают MAC, состояние подключения,
preferences и не подписываются на глобальные потоки. Эти шесть точек явно перечислены
в архитектурной проверке; расширять их обязанности нельзя. Замена общей подготовки UI
остаётся частью этапа D, удаления оставшегося старого кода — соответствующих шагов плана.

Чистый KMM enum `V3DeviceProfile` используется повторно. Классификатор устройства
не копируется. Строковые ключи domain сопоставимы с существующим протоколом;
проверка равенства не позволяет изменить их незаметно.

## Что проверяется автоматически

`V3ArchitectureTest` входит в обычный `:app:testDebugUnitTest` и проверяет:

- независимость domain от Android, data, presentation и DI;
- отсутствие зависимости data от presentation и ViewModel;
- отсутствие Repository и создания UseCase в presentation;
- вызов UseCase только из ViewModel;
- единственный вход `onAction` и read-only `uiState` у каждой ViewModel;
- отсутствие инфраструктуры и изменяемых потоков в UiState/Action;
- ограниченные точки совместимости с общим UI;
- соответствие domain-ключей существующим shared-идентификаторам.

Это проверки исходных зависимостей и публичного контракта, а не доказательство всех
возможных свойств архитектуры. Поведение дополнительно проверяется существующими
тестами экранов, domain и data. Добавлены сценарии загрузки профилей без применения,
смены устройства и запоздалого результата после отмены.

Правила для следующих изменений закреплены в
`app/src/main/java/com/bailout/stickk/ubi4/versions/v3/AGENTS.md`.

## Оставшаяся миграция

После этой проверки завершён C1.2.2: удаление, выбор и перестановка группы ротации
проходят через ViewModel/UseCase/Repository. На 2026-09-16 удалены неиспользуемый
GesturesDelegateAdapterV3, недоступный обработчик скрытого копирования и прямой путь
сохранения группы через Fragment. Адаптер V3 отображает группу из UiState, не читает
и не меняет WidgetState.rotationGroupGestures; общий список сохранён для UBI4.
Граница адаптеров защищена дополнительным тестом V3ArchitectureTest. После очистки
прошли 570 app-тестов (9 архитектурных), debug/release и 2 сценария на эмуляторе;
отображение V3 проверено с независимым общим списком UBI4. Телефон не использовался.

После C1.2.2 перенесены раздел/раскрытие коллекции (C1.3.1) и вход в редактор
пользовательского жеста (часть C1.3.2). Адаптер передаёт GestureSettingsRequested;
ViewModel хранит запрос в UiState. SprGestureFragment запускает прежнюю Activity
и синхронно подтверждает запуск. Только ViewModel вызывает UseCase сохранения номера;
data записывает прежний ключ preferences. Сохранены порядок запуска/записи, номера
1–14, ID 64–77 и аргументы Activity. Прежний прямой V3-путь из Base удалён.
На этом шаге прошли 597 app-тестов, обычные debug/release и 2 UI-сценария на эмуляторе
с проверкой Intent/сохранения номера на границе запуска Activity. Полный запуск редактора
на эмуляторе остановлен ошибкой компиляции шейдера внутри неизменённого 3D-рендера;
это не подтверждает работу полного редактора на устройстве. Его проверка на реальном
00001 не выполнялась: после ответа устройства редактор автоматически открывает пальцы.
Подробности и логи зафиксированы в основном плане.

Состав жестов V3 теперь принадлежит V3GesturesUiState.widgets. Источник и mapper
расположены в presentation/gestures/widgets; профиль и изменения сессии поступают
через UseCase. Прежние изменяемые структуры ограничены mapper, их метаданные
копируются. Прямые DataFactory/widgetListUpdater в SprGestureFragment остаются
только для UBI4. Проверены 607 app-тестов, debug/release и компиляция UI-тестов.
На Samsung с реальным 00001 проверены список, разделы, раскрытие и возврат из
Sensors/SpecialSettings; новых сбоев нет, исходные активный жест и группа сохранены.
В журнале переходов только GET активного жеста/группы. Окончательная release APK
установлена с сохранением данных и проверкой SHA-256. UBI4 аппаратно не проверялся.

Создание GesturesTwoSectionDelegateAdapterV3 и экранного CompositeDelegateAdapter
перенесено в SprGestureFragment. Из BaseWidgetsFragment удалены зависимости от
V3GesturesAction/UiState и адаптера жестов. В Base остаются общий lifecycle очистки
и обновление пользовательских имён в onResume; экран использует тот же список имён.
UBI4 использует прежний общий набор своих адаптеров. DataFactory-источники и mapper
не менялись. Пройдены 608 app-тестов (10 архитектурных), debug/release и компиляция
Android UI-тестов; проверка границ запрещает возвращать V3 gesture-зависимости в Base.
На Samsung с реальным 00001 проверены переходы между экранами, сворачивание/раскрытие
и сохранение состояния коллекции после возврата. Активный жест и группа сохранены,
новых сбоев нет; во время переходов только GET. Установленная release APK совпадает
с собранной по SHA-256. UBI4 и полный вход в редактор аппаратно здесь не проверялись.
