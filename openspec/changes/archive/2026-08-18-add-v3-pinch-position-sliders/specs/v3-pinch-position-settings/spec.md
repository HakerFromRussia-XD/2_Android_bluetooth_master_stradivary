## Purpose

Определяет единое для Android и iOS поведение глобальной настройки закрытого положения большого, указательного и среднего пальцев standard V3 для всех жестов устройства.

## ADDED Requirements

### Requirement: Standard V3 exposes two global closed-position controls
Система SHALL показывать в «Служебных настройках» standard V3 два независимых слайдера: «Закрытое положение большого пальца» и «Закрытое положение указательного/среднего пальцев». Первый слайдер SHALL управлять большим пальцем, а второй — указательным и средним пальцами как общей парой.

#### Scenario: User opens service settings for standard V3
- **WHEN** к Android- или iOS-приложению подключено устройство с профилем standard V3 и пользователь открывает «Служебные настройки»
- **THEN** экран содержит оба глобальных слайдера закрытого положения пальцев

#### Scenario: Non-standard profile opens settings
- **WHEN** подключено устройство INDY3 либо устройство с legacy-интерфейсом
- **THEN** система не добавляет два новых слайдера в набор виджетов этого устройства

### Requirement: Closed-position controls use the requested scale and presentation
Каждый новый слайдер SHALL принимать целое значение от `0` до `100` включительно с шагом `1`, где `0` означает полностью открытое положение, `100` — максимально закрытое положение, а промежуточное значение — соответствующую долю закрытия. Слайдер SHALL показывать текущее число без знака `%` и использовать существующее визуальное и интерактивное поведение V3-слайдеров чувствительности.

#### Scenario: User adjusts a closed position
- **WHEN** пользователь перемещает любой новый слайдер либо использует его кнопки уменьшения и увеличения
- **THEN** значение изменяется только целыми шагами в пределах `0…100` и отображается без единицы измерения

#### Scenario: User reaches a range boundary
- **WHEN** пользователь пытается уменьшить значение ниже `0` или увеличить выше `100`
- **THEN** система сохраняет ближайшее допустимое значение и не отправляет значение вне диапазона

### Requirement: Closed positions apply globally to every gesture
Система SHALL хранить одну глобальную пару положений и применять её ко всем жестам standard V3 без выбора жеста и без отдельных значений для разных жестов. Эти настройки SHALL управлять только большим, указательным и средним пальцами и SHALL не задавать положение безымянного пальца или мизинца.

#### Scenario: User changes the active gesture
- **WHEN** пользователь переключается с одного жеста standard V3 на любой другой
- **THEN** оба глобальных значения закрытого положения остаются теми же и продолжают применяться устройством

#### Scenario: User changes one global position
- **WHEN** пользователь изменяет положение большого пальца либо общей пары указательного/среднего пальцев
- **THEN** новое значение не связывается с текущим жестом и не создаёт отдельную копию настройки для других жестов

#### Scenario: Uncontrolled fingers participate in a gesture
- **WHEN** активный жест использует безымянный палец или мизинец
- **THEN** два новых параметра не задают закрытое положение этих пальцев

### Requirement: Initial global positions are read from the connected prosthesis
При начальной синхронизации standard V3 система SHALL запросить глобальное закрытое положение большого пальца командой `PWCE_GET_PINCH_THUMB_POSITION (0x45)` и общей пары указательного/среднего пальцев командой `PWCE_GET_PINCH_FINGER_POSITION (0x47)`, независимо сопоставить ответы параметрам и отобразить полученные значения на обеих платформах.

#### Scenario: Prosthesis returns both current positions
- **WHEN** устройство отвечает на команды `0x45` и `0x47` допустимыми значениями
- **THEN** соответствующие слайдеры Android и iOS показывают значения, фактически прочитанные с устройства

#### Scenario: User reconnects after an external device change
- **WHEN** значения были изменены вне текущего приложения и standard V3 подключается повторно
- **THEN** новая init-синхронизация заменяет локально известные значения актуальными значениями устройства

#### Scenario: INDY3 initializes
- **WHEN** приложение выполняет init-последовательность для профиля INDY3
- **THEN** команды `0x45` и `0x47` не отправляются и не учитываются в прогрессе его синхронизации

### Requirement: Each global closed position is written by its dedicated command
Система SHALL передавать выбранное целое значение `0…100` как однобайтовый scalar-параметр: для большого пальца через `PWCE_SET_PINCH_THUMB_POSITION (0x44)`, а для общей пары указательного/среднего пальцев через `PWCE_SET_PINCH_FINGER_POSITION (0x46)`. Техническое имя команды `PINCH` SHALL NOT отображаться пользователю как привязка настройки к жесту «Щёпоть».

#### Scenario: User commits a global thumb position
- **WHEN** пользователь завершает изменение слайдера положения большого пальца со значением `T`
- **THEN** приложение отправляет standard V3 команду `0x44` со значением `T` и не изменяет параметр указательного/среднего пальцев

#### Scenario: User commits a global index-middle position
- **WHEN** пользователь завершает изменение слайдера положения указательного/среднего пальцев со значением `F`
- **THEN** приложение отправляет standard V3 команду `0x46` со значением `F` и не изменяет параметр большого пальца

#### Scenario: Device reports an updated position
- **WHEN** приложение получает последующий корректный ответ чтения одного из параметров
- **THEN** состояние и соответствующий слайдер обновляются независимо от второго параметра

### Requirement: Existing standard V3 slider behavior remains consistent across platforms
Обе платформы SHALL использовать общий V3-контракт параметров для кодирования, разбора и хранения значений, а новые настройки SHALL участвовать в существующем поведении профилей настроек так же, как другие V3-слайдеры служебных настроек.

#### Scenario: User changes a value on either platform
- **WHEN** пользователь изменяет новый параметр на Android или iOS
- **THEN** обе платформы формируют эквивалентную V3-команду и сохраняют эквивалентное типизированное значение параметра

#### Scenario: User switches a settings profile
- **WHEN** существующий механизм профилей применяет сохранённый набор настроек standard V3
- **THEN** сохранённые положения пальцев восстанавливаются и отправляются устройству через соответствующие SET-команды
